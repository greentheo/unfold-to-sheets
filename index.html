Scale against waste

Stock size is fixed while the model grows, so each piece walks across the sheet until it no longer fits and then splits, leaving a dead offcut. The result is a sawtooth. Rows highlighted green are on the Pareto frontier — nothing else is both bigger and cheaper. Rows in red dropped a part and are disqualified, not merely annotated.
